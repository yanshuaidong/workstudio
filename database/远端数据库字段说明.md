## 各表字段

本文档按 MySQL 落库设计。字段单位与数值口径以采集后的标准化结果为准；原始接口字段映射由采集层维护，数据库结构不绑定具体接口字段名。

---

### `stock_basic_info`

主板/创业板等交易所证券静态信息。

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `exchange` | VARCHAR(16) | NOT NULL | 交易所标识，如 `SH`、`SZ`、`BJ` |
| `stock_code` | VARCHAR(16) | NOT NULL | 股票代码 |
| `stock_name` | VARCHAR(64) | NOT NULL | 股票简称 |
| `full_name` | VARCHAR(128) |  | 全称 |
| `board` | VARCHAR(32) |  | 板块 |
| `security_type` | VARCHAR(32) | NOT NULL | 证券类型 |
| `listing_date` | DATE |  | 上市日期 |
| `total_shares` | BIGINT |  | 总股本，按源数据口径入库 |
| `circulating_shares` | BIGINT |  | 流通股本，按源数据口径入库 |
| `created_at` | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| `updated_at` | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

**主键/约束**

- 主键：`PRIMARY KEY (exchange, stock_code)`
- 唯一约束：`UNIQUE KEY uk_stock_basic_code (stock_code)`

**索引**

- `KEY idx_stock_basic_board (board)`
- `KEY idx_stock_basic_security_type (security_type)`

### `stock_daily`

A 股日线/当日行情数据。

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `stock_code` | VARCHAR(16) | NOT NULL | 股票代码 |
| `stock_name` | VARCHAR(64) | NOT NULL | 股票名称，保留采集时名称 |
| `trade_date` | DATE | NOT NULL | 交易日 |
| `open` | DOUBLE |  | 开盘价 |
| `close` | DOUBLE |  | 收盘价/最新价 |
| `high` | DOUBLE |  | 最高价 |
| `low` | DOUBLE |  | 最低价 |
| `previous_close` | DOUBLE |  | 昨收价 |
| `volume` | BIGINT |  | 成交量，按标准化后的采集口径入库 |
| `volume_ratio` | DOUBLE |  | 量比 |
| `amount` | DOUBLE |  | 成交额，按标准化后的采集口径入库 |
| `amplitude` | DOUBLE |  | 振幅，百分比数值，如 `3.5` 表示 `3.5%` |
| `pct_change` | DOUBLE |  | 涨跌幅，百分比数值，如 `3.5` 表示 `3.5%` |
| `change_amount` | DOUBLE |  | 涨跌额 |
| `turnover_rate` | DOUBLE |  | 换手率，百分比数值 |
| `created_at` | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| `updated_at` | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

**主键/约束**

- 主键：`PRIMARY KEY (stock_code, trade_date)`

**索引**

- `KEY idx_stock_daily_trade_date (trade_date)`
- `KEY idx_stock_daily_code_date (stock_code, trade_date)`

### `stock_individual_fund_flow`

个股资金流数据。

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `stock_code` | VARCHAR(16) | NOT NULL | 股票代码 |
| `stock_name` | VARCHAR(64) | NOT NULL | 股票名称，保留采集时名称 |
| `trade_date` | DATE | NOT NULL | 交易日 |
| `latest_price` | DOUBLE |  | 最新价 |
| `pct_change` | DOUBLE |  | 涨跌幅，百分比数值，如 `3.5` 表示 `3.5%` |
| `main_net_inflow_amount` | DOUBLE |  | 今日主力净流入净额，按标准化后的采集口径入库 |
| `main_net_inflow_ratio` | DOUBLE |  | 今日主力净流入净占比，百分比数值 |
| `super_large_net_inflow_amount` | DOUBLE |  | 今日超大单净流入净额，按标准化后的采集口径入库 |
| `super_large_net_inflow_ratio` | DOUBLE |  | 今日超大单净流入净占比，百分比数值 |
| `large_net_inflow_amount` | DOUBLE |  | 今日大单净流入净额，按标准化后的采集口径入库 |
| `large_net_inflow_ratio` | DOUBLE |  | 今日大单净流入净占比，百分比数值 |
| `medium_net_inflow_amount` | DOUBLE |  | 今日中单净流入净额，按标准化后的采集口径入库 |
| `medium_net_inflow_ratio` | DOUBLE |  | 今日中单净流入净占比，百分比数值 |
| `small_net_inflow_amount` | DOUBLE |  | 今日小单净流入净额，按标准化后的采集口径入库 |
| `small_net_inflow_ratio` | DOUBLE |  | 今日小单净流入净占比，百分比数值 |
| `created_at` | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| `updated_at` | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

**主键/约束**

- 主键：`PRIMARY KEY (stock_code, trade_date)`

**索引**

- `KEY idx_fund_flow_trade_date (trade_date)`
- `KEY idx_fund_flow_code_date (stock_code, trade_date)`
- `KEY idx_fund_flow_main_amount (trade_date, main_net_inflow_amount)`
