# workstudio

**我们要做什么？**  
本地自动化采集，浏览器扩展抓页面数据，本地服务存结果。

**系统里的「任务」指什么？**  
一类**完整的采集作业**：目标明确，要把该类数据从页面抓到并写入本地（具体步骤见文末「单个任务怎么执行」）。手动模式可**单独**跑某一条，自动模式则按约定**顺序**一条接一条跑。任务1、任务2 这类编号是**工作计划上的单元**，不是程序里「消息队列」那种意义上的队列。

**什么是交易日？**  
指**中国 A 股市场**实际开市交易的日期：一般为周一至周五中有成交的日子；**不含**周六、周日，以及国家法定节假日和交易所另行公告的**休市日**（自动模式只在交易日触发）。

**有哪些运行模式？**  
- **自动**：交易日当天 **16:00** 起，按计划**依次**执行下面的任务。  
- **手动**：自己点选某个任务，主要用来测试；可随时单独跑其中一个。

**自动模式里目前有哪些任务？**  
- **任务1**：A 股日线（当前要做）。  
- **任务2**：个股资金流（当前要做）。  
- **任务3**：后续按需要再加。

**任务之间怎么间隔？**  
上一个任务结束（**无论成败**）等 **3 分钟**再跑下一个。

**怎样算失败 / 超时？**  
没网、请求失败、异常等都算失败；**单个任务**跑 **超过 30 分钟** 视为超时。

**单个任务怎么执行？**（一条任务从起到止的完整流程）  
1. **打开页面**：**新开**本任务对应的指定标签页（目标站点采集页）。  
2. **采集**：在该页上**自动翻页、抓数**（拦截列表接口、解析条目）。  
3. **写入本地**：采集中将各页结果**逐页提交到本地服务**落库；**本条任务告终**时再调用接口**结束本次 run**，汇总成功、失败或超时等最终状态。  
4. **关闭标签页**：本条任务执行完毕后（无论成功失败，含超时中止），**关闭本次用于采集的那一页**，再按需进入后续逻辑：**自动模式**下再等 **3 分钟**启动下一条任务；**手动模式**到此结束单次运行。

手动与自动的差异只在**触发方式**和**是否按计划连跑多条任务**；**单条任务**都按上面四步走完一圈。

**本地与远端数据库关系简述**  
- **本地数据库**：服务本地自动化与杂项数据。  
- **远端数据库**：存放股票等业务数据；与本项目在 `.env` 中配置的应用库名一致。

**远端 MySQL（当前环境摘要）**  
- **连接**：主机、端口、账号见项目根目录 `.env`文件。
- **服务端版本**：MySQL Community Server **8.0.46**。  
- **业务库**：
  - `stock`：股票相关的数据库。
  - 具体说明在database\远端数据库字段说明.md；
